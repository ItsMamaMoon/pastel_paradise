"Princess Toadstool made a cake for Mario, but she's feeling really down. Mario has to gather all the love in the world to make her feel better!"



Pastel Paradise is a total(ish) conversion dynos pack for Super Mario 64 Coop DX.

How to install: open SM64CoopDX, drag and drop the zip directly onto the main menu.
If you wish to install the dynos pack directly, drop the folder in your %appdata%, sm64coopdx\dynos.

Inside this zip file also contains an extras folder with custom palettes for each of the five playable coop characters, they can be dragged and dropped directly into sm64coopdx\palettes.
